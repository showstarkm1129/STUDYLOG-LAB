# STUDYLOGの機能を拡張し、不満点の解消、便利機能の追加を行います。

---

## 主な機能

1. 「Microsoft Authenticatorをインストール」を高速スキップ

面倒な追加2クリックを、文字を識別して表示された瞬間に自動でクリックします。


2. 前後の授業に移動できる機能

トップをいちいち開かなくても、1回の読み込みで前後の授業に移動することができます。


3. 終わっていない課題が一発でわかる

全ての課題を一覧で確認できます。さらに、取り組む必要の無いもの(試験の予備など)を選択して手動で完了扱いにすることもできます。


4. 欠席回数をシミュレートできる

欠席シミュレータにより、*D評価にならない範囲で何回休めるかを簡単に計算できます。

5. スタログ上の「クイズ」機能において、保存回数を増やす

ダイジェストなどで使われているあれのことです。本来、途中でセーブするには一度中断して戻らないと保存されませんが、この拡張機能では選択、入力終了ごとに保存します。回線などでの事故を減らすことができます。


6. iPORTALを開かずに記事を確認

簡易的な表示でiPORTALの記事を確認できます。本来iPORTALを開くには1度通信が発生しますが、これは開かないので通信が発生しません。また、未読を解消することもできます。

7. 曜日/科目 の単位で簡易メモ
簡易的なマークダウンに対応したメモを簡単に記入/閲覧できます。必要な道具、担当教師の性質のようなものをメモしておけば、それを簡単に閲覧でき、素早く適切な対処を取ることができます。
